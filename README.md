This repository contains research project work focused on feature construction using genetic algorithms with DEAP. The project is conducted in collaboration with Professor Azam and explores the application of evolutionary computation for automatic feature generation.

Overview

Utilizes DEAP (Distributed Evolutionary Algorithms in Python) to evolve expressions for feature construction.

Implements genetic programming to generate and optimize symbolic representations of features.

Uses K-Nearest Neighbors (KNN) for evaluating the constructed features.

Features

Custom Genetic Operators: Crossover, mutation, and selection tailored for feature construction.

Subtree Extraction: Extracts meaningful subexpressions from evolved individuals.

Performance Visualization: Tracks accuracy improvements across generations.

Integration with Machine Learning: Uses the transformed features in classification tasks.
